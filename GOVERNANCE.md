# Project Governance

## Contributions and maintenance

NVIDIA maintains Fleet Intelligence Out-of-Band Collector. NVIDIA employees and external contributors can propose changes through issues and pull requests using the same [contribution workflow](CONTRIBUTING.md#contribution-workflow).

Project maintainers review contributions and coordinate technical changes. Contributors interested in becoming maintainers should discuss the role and required access with the existing maintainers through a GitHub issue. Maintainer appointments and repository access require agreement from the existing maintainers; submitting contributions does not automatically grant these permissions.

## Official releases

Only authorized NVIDIA employees can create official releases at this time. Official publication through NGC requires NVIDIA-managed access and internal review and promotion steps. Maintainer status and release publishing access are separate responsibilities; external contributors can propose release fixes and documentation changes through pull requests.

The [release process](RELEASE.md) describes the current automation and the NGC publication requirement. There is currently no supported external release-manager process. Any future change to release eligibility must be reflected in this document, the [contribution guidelines](CONTRIBUTING.md#maintainer-and-release-roles), and the release process.
